# Devankshi's 1st Birthday — Invitation

Static invitation site (`index.html`). Deploy on Vercel (import this repo) or GitHub Pages.

- `index.html` — the invitation (photos embedded, countdown, RSVP, music)
- `Code.gs` + `RSVP-SETUP.md` — Google Sheets RSVP backend setup
- Set `RSVP_URL` in `index.html` to your Apps Script Web App URL
